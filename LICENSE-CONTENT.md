## Scope

| Material | Treatment |
| --- | --- |
| Original application logic, HTML structure, CSS, database schema, checks and technical documentation | MIT, except separately identified content embedded within them |
| Dictionary entries, definitions, historical equivalents, explanations, translations, source compilations and editorial prose | Existing dictionary content terms; no additional dataset license is granted here |

## Existing dictionary terms

The repository's [Turkish terms](kullanim-sartlari/index.html) and [English terms](en/terms-of-use/index.html) permit use through academic citation and limited quotation and address unauthorized bulk copying, repackaging and commercial reproduction as an independent dictionary data source. This notice preserves that distinction; it does not introduce a Creative Commons license or relicense third-party material.

For the published service, consult the [current dictionary terms](https://askeriterimlersozlugu.com/kullanim-sartlari/). Requests beyond those terms should be directed to the maintainer through the dictionary's contact page.
